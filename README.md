## Portfolio Architecture

The platform brings together three major components:

- **Public Portfolio:** The visitor-facing experience for exploring projects, skills, achievements, and professional information.
- **Admin Dashboard:** A dedicated content management interface for managing portfolio information.
- **Backend Services:** The application services responsible for portfolio data, administration, and dynamic functionality.

Portfolio content is dynamically managed, allowing updates without manually modifying the presentation components.
